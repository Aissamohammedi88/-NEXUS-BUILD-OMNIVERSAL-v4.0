# 🔥 NEXUS FORGE — Manifeste de la Révolution

- Chaque développeur doit être indépendant
- Aucune entreprise ne doit contrôler le code
- La valeur doit revenir aux créateurs
- Les dépôts doivent être libres

## Nous refusons :
- La dépendance à GitHub
- La fermeture arbitraire de comptes
- La vente de données
- Le contrôle centralisé

## Nous construisons :
- Une forge décentralisée
- Une bourse pour les développeurs
- Une identité Nexus
- Un écosystème indépendant
